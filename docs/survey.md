# 사용자 설문 (11/11~11/13)

목적: 기획서의 MAU 가정(설치율)과 문제의 크기를 실제 응답으로 좁힙니다. Google Forms에 그대로 옮겨 쓰면 됩니다.

- 대상: 운전면허가 있는 사람. 40~50대를 최소 15명, 전체 30명 이상
- 배포: 가족·지인 단톡방, 학과·동아리, 맘카페나 초보운전 카페(카페 규칙 확인 후)
- 소요 시간: 2분 안쪽

## 문항

1. 나이대 — 20대 / 30대 / 40대 / 50대 / 60대 이상
2. 운전 빈도 — 거의 매일 / 주 2~3회 / 주 1회 이하 / 면허만 있고 거의 안 함
3. 지금 주로 타는 차 — 현대·기아 승용 / 현대·기아 SUV·RV / 다른 브랜드 / 차 없음
4. 처음 가는 길을 운전하기 전에 로드뷰나 모의주행으로 미리 길을 본 적이 있나요? — 자주 / 가끔 / 없음
5. 합류 구간, IC, 회전교차로가 부담돼서 일부러 다른 길로 돌아간 적이 있나요? — 자주 / 가끔 / 없음
6. 가장 부담되는 상황을 모두 골라 주세요 — 고속도로·자동차전용도로 합류 / IC 진출입 / 회전교차로 / 차로 변경 / 비보호 좌회전 / 길을 놓쳤을 때 / 주차 / 기타
7. 운전이 불안할 때 옆자리 사람에게 길 안내를 부탁한 적이 있나요? — 자주 / 가끔 / 없음
8. (컨셉 소개를 읽은 뒤) "어려운 지점에서만 미리 말해 주고, 길을 놓치면 '괜찮아요, 2분만 더 걸려요'라고 말해 주고, 익숙해지면 말을 줄이는 차량 앱"이 있다면 켜 보시겠어요? — 꼭 켠다 / 켜 볼 것 같다 / 모르겠다 / 안 켤 것 같다
9. 이런 안내가 오히려 거슬릴 것 같은 점이 있다면 적어 주세요 (주관식, 선택)
10. 운전하면서 불편했던 경험을 자유롭게 적어 주세요 (주관식, 선택)

### 컨셉 소개 (8번 문항 앞에 붙일 문구)

> 내비가 처음부터 끝까지 말하는 대신, 합류·IC·회전교차로 같은 어려운 지점에서만 1km 전과 400m 전에 짧게 미리 말해 줍니다. 깜빡이를 켜고 지나가면 "합류 구간 지나왔어요"라고 사실만 말하고, 길을 놓치면 "괜찮아요, 2분만 더 걸려요"라고 말합니다. 같은 지점을 여러 번 잘 지나면 안내를 스스로 줄입니다.

## 기획서에 쓰는 방법

| 결과 | 기획서 반영 |
| --- | --- |
| 5번 '자주+가끔' 비율 | 문제의 크기 (합류·회전교차로 때문에 우회한 경험) |
| 8번 '꼭 켠다+켜 볼 것 같다' 비율 | 설치율 가정 교체 (현재 5~15% 가정) |
| 6번 상위 항목 | 1차 범위(합류·IC·회전교차로)가 맞는지 확인 |
| 4·7번 | '로드뷰·인간 내비' 우회 행동의 근거 |
| 9번 | 리스크(거슬림)와 안내 줄이기 설계 근거 |

표본이 작고 지인 중심이므로 기획서에는 "응답자 N명, 지인·커뮤니티 모집, 대표성 제한"을 함께 적습니다.
