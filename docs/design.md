# 설계 요약 (개발 기준)

기획서 v2(2026-11-10)에서 코드가 따라야 할 결정만 모았습니다. 기획서와 다르면 이 문서를 먼저 고치고 코드를 맞춥니다.

## 1. 범위

- 다루는 어려운 지점: 합류, IC 진입·진출, 분기, 회전교차로, 주의 지점(급커브·좁은 길)
- 다루지 않는 것: 비보호 좌회전(신호 방식 데이터 없음), 차로 번호 안내(차로 데이터 없음), 운전 점수·순위, 주행 중 실수 지적, 주행 중 화면 조작, 기본 내비 대체

## 2. 어려운 지점 판정

"지나왔어요"는 아래 조건이 **모두** 확인될 때만 말합니다. 하나라도 확인할 수 없으면 침묵하고 기록에는 `UNCERTAIN`으로 남깁니다.

| 종류 | 데이터 | 조건 |
| --- | --- | --- |
| 합류 | TBT TurnType `TURN_DEVIDE_MERGE` | ① 남은 거리 0m 전에 같은 방향 깜빡이 점등 ② 재탐색 없이 다음 회전 안내로 넘어감 ③ 통과 후 10초간 급제동 없음 |
| IC 진입·진출 | TBT IC 종류 | ①②③ |
| 분기 | TBT 분기 종류 | ②③ (깜빡이는 기록만) |
| 회전교차로 | TBT 회전교차로 종류 | ②③ |
| 주의 지점 | CautionPoint | 안내만, 판정 없음 |

- **급제동**: 브레이크를 밟은 상태에서 1초에 12km/h 이상 감속, 그리고 감속 전 속도 30km/h 이상 (정체 구간의 일상 제동 제외)
- **재탐색**: 재탐색 이벤트가 있으면 사용. 없으면 "다음 지점까지 남은 거리가 다시 늘어남 + ETA 증가"로 추정
- 판정 결과: `PASSED`, `PASSED_WITHOUT_SIGNAL`(깜빡이 조건만 미충족, 침묵), `MISSED`(재탐색), `UNCERTAIN`

## 3. 발화 규칙

| 시점 | 문장 | 조건 |
| --- | --- | --- |
| 1km 전 | "곧 오른쪽으로 합류해요." | 안내 줄이기 단계가 허용할 때 |
| 400m 전 | "400m 뒤 오른쪽 합류, 깜빡이 먼저요." | 같은 방향 깜빡이가 **꺼져 있을 때만** |
| 통과 후 | "합류 구간 지나왔어요. 깜빡이도 미리 켰어요." | 판정 `PASSED`일 때만 |
| 재탐색 | "괜찮아요, N분만 더 걸려요." (N = 새 ETA − 이전 ETA, 1분 미만이면 "금방이에요") | 재탐색 감지 시 |

- 지점당 최대 3마디
- 침묵: 조향각 30° 초과, 급제동 후 20초, 기본 내비가 말하는 중
- 큐에서 10초가 지난 문장은 버림
- 도로 상황 판단("틈이 충분해요")과 운전 지시("속도 맞춰요")는 하지 않음
- 첫 실행 시 고지: "옆자리 친구는 도로를 보지 못하는 보조 안내입니다. 판단과 운전 책임은 운전자에게 있습니다."

## 4. 안내 줄이기 (F12)

같은 종류 지점을 연속으로 `PASSED`하면 그 종류의 안내를 줄입니다.

| 연속 PASSED | 1km | 400m | 통과 후 |
| --- | --- | --- | --- |
| 0~4 | O | O (깜빡이 꺼짐일 때) | O |
| 5~9 | X | O (깜빡이 꺼짐일 때) | X |
| 10+ | X | X | X |

`MISSED`가 나오면 그 종류의 연속 횟수는 0으로 돌아갑니다. 사용자는 설정에서 되돌릴 수 있습니다.

## 5. 연습 사다리

| 단계 | 내용 | 다음 단계 조건 |
| --- | --- | --- |
| 1 | 동네길: 회전교차로, 유턴 | 회전교차로 PASSED 3번 |
| 2 | 간선도로 분기 | 분기 PASSED 5번 |
| 3 | 자동차전용도로 합류 | 합류 PASSED 5번 (깜빡이 포함) |
| 4 | 고속도로 IC 합류 | — |

## 6. 우선순위

- P0 (시연 필수): F3 사전 안내, F4 보수적 판정, F5 차분한 재탐색, F6 발화 예산, F8 내 기록, F9 시뮬레이션·신호 주입 패널
- P1: F1 길 난이도, F2 편한 길(COMFORTABLE), F10 연습 사다리, F11 자주 가는 길 기억, F12 안내 줄이기
- P2: F7 급제동 뒤 공조·조명, F13 비보호 좌회전, F14 연수·보험 리포트

## 7. 확인 관문 (2026-11-13)

| 결과 | 제출 범위 |
| --- | --- |
| 회전 안내·방향지시등 모두 받을 수 있음 | 현재 설계 그대로 |
| 회전 안내만 받을 수 있음 | 사전 안내 + 차분한 재탐색 + 안내 줄이기. 깜빡이 조건은 지원 차종부터 |
| 회전 안내를 받을 수 없음 | 주제 재검토 |
