# 시연 장면 대본

## merge_signal_early — 합류 600m 전에 오른쪽 깜빡이를 켜고 합류

- 00:30 곧 오른쪽 합류예요.
- 01:37 합류 구간 지나왔어요. 깜빡이도 미리 켰어요.

판정: MERGE PASSED

주차 후 요약: 오늘 합류 구간 1번 지나왔어요.
