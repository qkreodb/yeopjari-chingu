# 시연 영상 대본 (목표 2분)

옆자리 친구 시연 영상의 촬영 순서와 편집 계획입니다. 앱의 시연 경로(오른쪽 합류 → 좌회전 → 오른쪽 IC → 도착)를 한 번 끝까지 달리며 찍고, 편집에서 빈 구간만 빠르게 돌립니다.

## 전하고 싶은 것

1. 어려운 지점(합류·IC)에서만, 미리 두 번 말한다.
2. 차량 신호로 **확인한 사실만** 말한다. 깜빡이를 켜는 걸 봤을 때만 칭찬하고, 꺼져 있으면 "꺼져 있어요"라고 사실만 말한다.
3. 결과는 점수가 아니라 "오늘 지나온 곳"으로 남는다.

## 촬영 전 준비

1. Android Studio를 닫는다(메모리). 에뮬레이터를 켜고 Virtual Console(`http://127.0.0.1:8088/`)을 연다.
2. 화면 배치: 왼쪽에 에뮬레이터, 오른쪽에 브라우저(Virtual Console, **Turn Signal State** 카드가 보이게).
3. 앱을 지우고 다시 설치해 안전 고지부터 나오게 한다. 앱은 아직 열지 않는다.
   `adb uninstall com.yeopjari.chingu` → `adb install apk/박대유_옆자리친구_release.apk` → `adb shell pm grant com.yeopjari.chingu android.car.permission.CAR_SPEED`
4. Turn Signal State는 **Off**.
5. 녹화: Windows **캡처 도구**(Win+Shift+S → 녹화 → 영역 선택). 에뮬레이터와 브라우저를 함께 잡는다. 녹화 막대에서 **시스템 오디오를 켠다**(앱 음성이 PC 스피커로 나온다).
6. 주의:
   - Ctrl 키를 누르지 않는다(에뮬레이터에 멀티터치 동그라미가 뜬다).
   - 깜빡이를 켜면 Pleos가 측후방 카메라 창을 띄운다. 2~3초 보여 준 뒤 X로 닫는다. "실제 차량 신호와 연동된다"는 증거라 잠깐 보여 주는 편이 낫다.

## 편집 (3분 → 약 2분)

- 0:14~0:34, 1:07~1:37, 2:38~3:00 구간을 2~3배속으로 돌린다. 음성이 나오는 구간은 원래 속도를 유지한다.
- 시작 카드(5초): "옆자리 친구 — 운전이 불안한 사람을 위한 차분한 동승 내비 / 2026 현대자동차그룹 차량용 앱 개발 공모전"
- 끝 카드(10초), 한 줄씩:
  - 급제동 직후 20초, 핸들을 30° 넘게 꺾는 동안은 말하지 않아요.
  - 길을 놓치면 "괜찮아요, N분만 더 걸려요."
  - 같은 곳을 다섯 번 잘 지나면 안내가 줄고, 열 번이면 조용해져요.
  - 끝 카드의 세 줄은 판정 엔진 테스트로 확인한 동작입니다. 재탐색은 이 시연 경로에 없어서 영상에 나오지 않습니다.
- 배경음악은 넣지 않거나 아주 작게 넣는다(앱 음성이 핵심).

## 선택: 급제동 장면 (짧게 추가할 때)

1. 앱 새로 시작 → Off 상태로 '합류 시연 시작'.
2. **0:28~0:33 사이**에 **'급제동'** 클릭.
   - 0:26 전에 누르면 침묵 20초가 먼저 끝나서, 400m 안내가 늦게(약 300m 지점에서) 나온다.
   - 0:41 뒤에 누르면 합류 판정이 '판정 보류'가 된다.
3. 400m 지점(약 0:36)에서 아무 말도 하지 않는 것을 보여 준다. 자막: "급제동 직후에는 말을 멈춘다".
4. 20초 분량을 5초로 줄여 끝 카드 앞에 넣는다.
